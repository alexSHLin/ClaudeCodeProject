## 使用 Python 環境管理

使用 uv 管理 Python 執行環境：

- 必要時使用 uv init 初始化資料夾
- 使用 uv add 加入套件，不要使用 pip（開發用套件用 `uv add --dev`）
- 使用 uv run 執行 Python 腳本檔
