# 網頁版產品需求

## 啟動網頁版

- 原程式執行時若沒有加上任何命令行引數，就啟動成為網頁伺服器，等候 5050 連接埠準備連線，顯示網址
- 若有加上命令行引數，就依
  照原命令行工具運作

## 前端網頁

放置在 front_end 資料夾中。

## 網頁外觀

- 背景使用漫畫風格的底圖，自行生成
- 畫面上有一個修復前、修復後拖拉對比的圖片
- 版面如下:

  ```
                  +----------------+
  Upload Image：|                |
                  +----------------+
                  +----------------+
         放大倍數：|                |
                  +----------------+
                  +------+
                  | Start |
                  +------+
  ```

  ## 運作流程

1. 按一下 `Upload Image` 欄位或將圖片拖入，即可選取 圖片檔上傳
2. 圖片未上傳或放大倍數未輸入時，無法按下 'Start ' 鈕
   3 按 `Start` 後處理圖片無損放大
3. 處理好的 image 檔放在 upscale 資料夾下。
